# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive; no harassment, discrimination, personal attacks or publishing others' private information. Maintainers may remove, edit or reject contributions and may ban contributors who violate these standards.

Report unacceptable behaviour privately to the maintainers through GitHub (Security → Report a vulnerability is acceptable for confidential reports). All reports are reviewed and kept confidential.
