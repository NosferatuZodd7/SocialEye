## [0.1.0] - 2026-11-26
### Added
- Tauri 2 desktop app (Windows 10/11) with React, TypeScript and Tailwind; dark and light themes; English and Portuguese (Portugal).
- SQLite storage with versioned migrations, backup/restore, JSON export and audit log.
- OAuth 2.0 + PKCE loopback sign-in for Google, Meta and Spotify; tokens in Windows Credential Manager; automatic refresh and expiry monitoring.
- YouTube: channels, videos, analytics (daily, per video, traffic sources, demographics, geography, retention), comments moderation, resumable upload, metadata editing, thumbnails, scheduling.
- Facebook Pages: stats, insights, posts, comment moderation, publishing and scheduling.
- Instagram professional accounts: stats, insights, media, comment moderation, publishing, local scheduling; follower analysis from official data exports (JSON/HTML).
- Spotify podcasts: catalogue sync and Spotify for Creators CSV analytics import.
- Content studio with drafts, per-platform versions and validation, media library, templates, history, calendar.
- Unified analytics, reports (PDF/CSV/Excel), automations and notification center.
- CI for lint, types, tests, clippy and Windows installers; release workflow.
